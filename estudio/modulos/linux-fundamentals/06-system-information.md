# 6 de 30 — System Information

**Estado:** Completado

## Resumen

Comandos principales:

```bash
whoami
id
hostname
uname -a
pwd
ip addr
lsblk
lsusb
lscpu
```

Permiten reconocer usuario, grupos, host, kernel, arquitectura, red, discos y procesador.

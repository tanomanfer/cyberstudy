# 4 de 30 — Prompt Description

**Estado:** Completado

## Resumen

Un prompt como `usuario@servidor:~$` informa el usuario, el host, la ubicación actual y los privilegios. Normalmente `$` corresponde a un usuario común y `#` a `root`.

## Qué aprendí

Aprendí a leer el prompt y a distinguir la PC local de una máquina objetivo conectada mediante SSH.
